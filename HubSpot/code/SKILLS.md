# SKILLS.md

Core competencies for Power BI report design
============================================

Advanced information design
---------------------------
- Visual hierarchy: apply Z-pattern or F-pattern reading so the most critical KPIs live in the top-left.
- Data-to-ink ratio: remove non-critical elements (gridlines, heavy borders, redundant labels).
- Persona mapping: tailor granularity and interaction by role and decision authority.
- Responsive design: build layouts that scale across desktop, tablet, and mobile using native container settings.

Technical visualization excellence
----------------------------------
- Chart selection: match the visual to the story (waterfall for variance, bullet for target vs actual, sparkline for trend context).
- DAX/SQL optimization: push calculations to the source where possible and optimize measures to reduce visual load times.
- Metadata management: enforce UI consistency via the Common Branding Guide JSON (see `docs/powerbi/Branding_Guide.json`).

# BI Development & Information Design Skills

## Visual Hierarchy & UX
* **Z-Pattern Layout:** Designing report canvases to align with natural scanning patterns, placing critical KPIs in the top-left quadrant.
* **Data-to-Ink Ratio Optimization:** Expertise in stripping away non-essential elements (gridlines, heavy borders) to emphasize core data points.
* **Persona-Based Design:** The ability to pivot granularity based on the audience (Executive vs. Tactical).

## Technical Visualization
* **Chart Logic:** Selecting visual types based on data relationships (e.g., Waterfall for variance, Bullet charts for Target vs. Actual).
* **Responsive Design:** Building reports that scale across desktop, tablet, and mobile orientations using native container settings.

## Performance Engineering
* **DAX/SQL Optimization:** Pushing transformation logic upstream to the data source to minimize visual render time.
* **Metadata Management:** Leveraging the "Common Branding Guide" JSON to ensure 100% UI consistency across all workspaces.
